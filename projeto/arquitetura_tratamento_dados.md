# Arquitetura

A arquitetura do projeto representa a estrutura fundamental do sistema, permitindo que seja exemplificado, de forma visual, o processo que propõe o fluxo completo para tratamento e análise de dados, estruturado tanto para suportar o processamento de dados estáticos quanto uma futura automação do pipeline.
Uma observação importante do escopo atual do projeto é que os dados utilizados são estáticos, tornando a orquestração (parte da automação do pipeline) dispensável. No entanto, caso a empresa opte por integrar dados dinâmicos, a infraestrutura Azure já está preparada para receber a camada de orquestração via Azure Data Factory sem necessidade de reestruturação
