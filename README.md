# Atlas de Potencial Comercial
`Curso de Tecnologia em Banco de Dados`
`2026/5°Semestre`

O projeto tem como objetivo identificar com maior precisão o potencial de mercado por município para o Grupo Comolatti, distribuidora nacional de peças automotivas com cerca de 120 filiais no Brasil. Para isso, serão desenvolvidos indicadores como motorização (veículos por habitante), intensidade de consumo de combustível, quantidade de clientes por município e um índice combinado de potencial de mercado, construídos a partir de dados públicos de população, vendas de veículos e comercialização de combustíveis.

A proposta é adotar uma abordagem analítica que permita compreender as particularidades econômicas e o perfil de consumo de cada região, apoiando decisões comerciais mais assertivas. Com base nesses indicadores, será possível regionalizar as estratégias de vendas, otimizando estoques, ajustando políticas comerciais e melhorando a logística, de forma a alinhar melhor a oferta à demanda em cada localidade.
